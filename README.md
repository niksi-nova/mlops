# AI-Assisted Public Transport Information System - Transit Delay Prediction (Delhi Bus GPS)

This project has moved from the Toronto TTC bus delay dataset to a Delhi (India) bus GPS dataset.

The previous TTC version is preserved at git tag `ttc-final` (branch `archive/ttc-version`).
