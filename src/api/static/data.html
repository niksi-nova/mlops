Data — what's actually in here

Delhi public bus GPS/stop-event data, two routes (425, 534), both directions. See the dataset card on GitHub for the full write-up.

Limitations

  • Only 2 routes (425, 534) - this is not a city-wide model.
  • No real vehicle GPS coordinates - only stop-sequence node indices.
  • No real calendar dates in the raw data, only relative day_index/weekday labels.
  • Real-time features (previous bus, headway) require a live feed this project doesn't build - see About.
