About

What this predicts

For one stop-to-stop segment of a Delhi bus route, the model predicts travel_time_s — how many seconds that bus takes to cross that segment, given 25 pre-computed features (position on the route, time of day, and real-time conditions like the previous bus's travel time and the gap since it passed).

Honest caveat: the API takes those 25 features as input — it does not compute any of them itself. In particular, the real-time ones (previous bus travel time, median of the last 3 buses, headway, buses in the recent window, has-previous-bus) must be supplied by the caller. The Counter page on this site fills them in with real historical medians for the chosen segment and hour, as a stand-in for a live feed this project doesn't build.

Data limitations

  • Only two routes (425, 534) in both directions — not a city-wide model.
  • No real GPS coordinates, only stop-sequence node indices.
  • No real calendar dates — only relative day indices and weekdays.
  • See Data for the full breakdown and the dataset card in the repo.
